# 📊 Sales Data Analysis (SQL + Power BI)

## ⭐ Project Highlights
- End-to-end sales data analysis using SQL and Power BI  
- Built interactive dashboards for business insights  
- Extracted actionable insights to improve decision-making  

---

## 🚀 Project Overview
This project analyzes sales data to uncover trends, patterns, and key performance metrics. SQL was used for data analysis, and Power BI was used to create an interactive dashboard for visualization.

---

## 🎯 Objectives
- Analyze sales performance over time  
- Identify top-performing products  
- Understand regional sales distribution  
- Track key business KPIs  
- Build an interactive dashboard  

---

## 🛠️ Tools & Technologies
- SQL  
- Power BI  
- Excel / CSV  

---
